# Roadmap

## Done: devotional theme and library (this release)

Deity paintings in temple arches with marigold garlands, a toran across the home page, a palm-leaf shelf for the library, lotus dividers and a petal shower. Six categories, deity pages, a chapter-by-chapter Gita reader, and 30 texts written in a plain-text format that a build script checks.

## Next: content

1. **Proofread what exists.** Check every line against a named printed edition, record it in a `source:` line, and show a “proofread” mark on the text.
2. **The most requested texts:** Shiv, Durga, Ganesh, Lakshmi and Saraswati Chalisas; Bajrang Baan; Shiv Tandav Stotram; Aditya Hridayam for Surya and Chhath; Durga Saptashati; Vishnu Sahasranama; the Sundarkand; the rest of the Gita.
3. **Regional collections**, each in its own script: the Marathi aarti set (Durge Durghat Bhari, Lavthavati Vikrala, Ghalin Lotangan), Gujarati, Bengali, Odia, Tamil, Telugu and Kannada traditions.
4. **Sources and rights.** Only public-domain texts: traditional works, saint-poets, and printings old enough to be free. Film songs and modern bhajans are copyrighted and stay out. Translations are written for the project, or taken from translations old enough to be in the public domain. Check each digital source’s terms (GRETIL, Wikisource, sanskritdocuments.org) before importing from it.

## Then: reach and speed

- A static page per text, so search engines index them and WhatsApp shows a proper preview when a link is shared
- Offline use after the first visit, for temples with weak signal
- Copies of the paintings in the repository instead of loading them from Wikimedia
- Load long granths a chapter at a time once the library grows
- A Hindi interface option
- Audio, recorded for the project

## Ongoing: corrections from readers

Every text links to a pre-filled GitHub issue for corrections. A correction is accepted once it is checked against a printed edition.
